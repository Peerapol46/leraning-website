# อัปเดตการบันทึกผลแบบทดสอบ
1. แทนที่ Code.gs ใน Apps Script ของชีตเดิมด้วยเวอร์ชันล่าสุด
2. รัน setupSheets เพื่อเตรียมเฉพาะชีตแบบทดสอบก่อนเรียนและแบบทดสอบหลังเรียน
3. Deploy → Manage deployments → Edit → New version โดยใช้ URL เดิม
4. ทดสอบส่งแบบทดสอบและตรวจใบรับ ต้องไม่เพิ่มแถวซ้ำเมื่อส่งรายการเดิม

ผลฝึกติดตั้ง Windows แสดงเฉพาะในเว็บ ไม่มีฟอร์มส่งผลและไม่มีการบันทึกไป Google Sheets โค้ดนี้ไม่สร้างหรือลบชีตผลฝึกเดิม หากมีชีตเดิมอยู่ ข้อมูลจะยังคงอยู่
